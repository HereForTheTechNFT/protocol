# Architecture de Reserve Protocol

Le dépôt distingue les contrats de spécification, les implémentations optimisées et les plugins. Les modules d’actifs décrivent comment un collatéral est valorisé et manipulé ; les modules de trading encadrent les échanges nécessaires au rééquilibrage.

Cette séparation permet de composer un RToken à partir de garanties différentes tout en conservant un noyau commun : gouvernance, registre, émission, rachat et gestion du risque.
