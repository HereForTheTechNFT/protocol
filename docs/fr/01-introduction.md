# Reserve Protocol : introduction

Reserve permet de créer des RTokens, des actifs émis contre un panier de collatéraux. Le dépôt sépare le protocole économique, les plugins d’actifs et les mécanismes de trading.

L’objectif de ce parcours est de relier les contrats Solidity aux garanties annoncées : émission, rachat, surcollatéralisation, rééquilibrage et gestion d’un défaut. Les chapitres décrivent le code présent et ses hypothèses ; ils ne constituent pas un audit.
